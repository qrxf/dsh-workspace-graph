# DeepSeek Harness 工作区图谱插件框架

日期：2026-10-24。拟用名称：dsh-workspace-graph。

这是设计与开发交接文档，还不是可安装插件。用户已明确目标为 DeepSeek Harness。GPT-6.1 Sol 已参与补全实施顺序、接口边界与验收标准；尚未编写产品代码或执行安装。

## 已确定的需求

图形化管理工作区，参考截图中的气泡与连线；气泡可以拖动，左下角可以选择。

本框架建议大气泡代表工作区、小气泡代表会话，连线表示所属。左下角同时提供工作区选择和筛选。右侧详情、搜索及管理动作是建议的产品设计，尚未逐项确认。

## 页面框架

```text
┌─────────────────────────────────────────────────────────┐
│ 工作区图谱    搜索名称…             适应画布  重置布局    │
├───────────────────────────────────────────┬─────────────┤
│       ○ 会话 A                            │ 详情面板    │
│        ╲                                  │ 名称 / 路径 │
│         ● 工作区一 ── ○ 会话 B            │ 状态 / 时间 │
│                                           │             │
│                       ● 工作区二          │ 打开会话    │
│                      ╱         ╲          │ 新建会话    │
│                  ○ 会话 C    ○ 会话 D     │ 重命名      │
│ ┌─────────────────────────────────────┐   │ 归档/恢复   │
│ │ 工作区：全部 ▾                      │   │             │
│ │ 状态：全部 / 运行中 / 等待 / 空闲    │   │             │
│ │ 类型：工作区 / 会话   显示归档 □     │   │             │
│ └─────────────────────────────────────┘   │             │
└───────────────────────────────────────────┴─────────────┘
```

视觉：深蓝背景、柔和圆形气泡、细连线、清晰标签。工作区大圆，会话小圆；状态同时使用文字或图标。长标题截断，悬停显示全文。详情面板可收起。

## 交互约定

| 操作 | 结果 |
| --- | --- |
| 拖动气泡 | 仅改变位置，松手保存；不移动目录、不改变会话所属 |
| 拖动背景、滚轮 | 平移、缩放；左下角面板固定 |
| 单击气泡 | 选中并查看详情；拖动结束不能误触打开 |
| 双击会话或点击打开 | 通过宿主导航进入会话；返回保留视角 |
| 展开工作区 | 显示所属会话；大工作区按需展开 |
| 左下角选择工作区 | 选择全部或指定工作区，保留各范围视角 |
| 状态、类型、归档筛选 | 只改变可见性，保留隐藏节点及其布局 |
| 搜索 | 按名称定位；隐藏的匹配项提供显示并定位操作 |
| 适应画布 | 改变视角，不重新排布 |
| 重置布局 | 明确触发重排并可撤销；刷新和状态更新不重排 |

首版归档默认隐藏，未归属会话置于未分组区域。归档会话的打开和恢复遵循宿主规则。状态只映射宿主实际值，没有数据时显示未知，不能把空闲推断为完成。

## 架构与取舍

推荐新增 DSH 原生插件页面，保留现有侧栏。相比替换侧栏，这能减少对原导航的影响；相比独立展示网页，更便于复用真实管理能力。这是本框架的建议方案。

技术候选：TypeScript、宿主兼容的 React、React Flow 自定义圆形节点。先核实客户端加载与依赖约定，不重复打包 React。首版采用确定性的初始布局，后续可加环形或树形布局。

```text
图谱页面
 ├─ GraphCanvas：气泡、连线、拖动、选择、缩放
 ├─ FilterDock：左下角工作区选择、状态/类型筛选
 ├─ DetailPanel：详情与管理动作
 └─ GraphState：视角、选择、可见图、布局历史
       ├─ HarnessAdapter：读取、订阅、导航、宿主管理动作
       │    └─ DSH 已安装版本支持的 client / host 接口
       └─ LayoutRepository：布局与偏好持久化
            └─ 插件独立存储命名空间
```

这些模块名是建议的内部划分，不是已存在的 DSH API。

## 数据边界

Workspace / Session 原生记录为真源。插件另存位置、折叠、视角及筛选偏好，不复制维护会话正文。

- NodeRef：节点类型，以及真实 workspaceId 或 sessionId；使用带类型前缀的稳定 ID。
- GraphNode：引用、宿主标题及状态、画布位置。名称和路径不能作为唯一标识。
- GraphEdge：源、目标、关系类型；首版只展示真实所属关系。
- LayoutDocument：schemaVersion、宿主/profile隔离键、视图范围、位置映射、折叠集合、视角、筛选与修订号。

拖动中更新内存，松手保存；保存失败显示未保存及重试入口。新增节点安排初始位置，既有节点保持不变。筛选后的可见子集不能覆盖完整布局。多窗口写入需要冲突检测或明确的覆盖策略。宿主删除对象后清理失效引用，不误判尚未加载的分页数据为已删除。

## 首版及后续

首版：读取真实工作区与会话、显示所属关系、拖拽保存、左下角选择筛选、搜索定位、打开会话、适应画布、中文空态与错误提示。

第二阶段：通过宿主允许的操作新建会话、重命名、归档/恢复，遵循运行中限制与权限拒绝。删除工作区注册不同于磁盘删除；首版不提供删除磁盘文件。

可选扩展：环形/树形布局、标签、人工关联、文件节点、布局导入导出。人工关联须区别于真实所属关系。自动读文件、生成主题关系及批量代理调度不纳入首版。

## 接入前核实

当前目录没有 DSH 源码或已安装版本信息，实际接口仍需核验：

1. DSH 版本、运行方式、目标 profile、插件包格式及加载入口。
2. 新增页面及侧栏入口的实际 slot/导航契约。
3. 工作区/会话的快照、订阅、分页、状态和权限接口。
4. 插件存储机制、宿主/profile隔离和多窗口冲突策略。
5. 插件卸载及重启后的订阅释放与布局恢复。

官方源码文档提供 ctx.uiWorkspace.openSession、openWorkspace 作为导航调查入口，并说明 slots.inject 的注册生命周期。host 的 ctx.workspaceRegistry 不应直接从浏览器组件调用。以上均须与实际安装版本比对，不编造未核实的全局页面 slot、订阅或存储接口。

## GPT-6.1 Sol 开发交接

6.1 Sol 已参与本框架审阅。后续实现按以下顺序执行：

1. 核验实际 DSH 版本和接口，记录兼容范围；无法确认挂载入口时先定位官方实例。
2. 创建独立图谱页与样例数据，完成布局和交互；演示数据须明确标识。
3. 接入真实宿主数据，验证所属、状态、打开对象与权限。
4. 接入布局保存、事件增量更新、错误恢复及生命周期释放。
5. 完成验证后提供可安装包、安装说明、兼容版本和已知限制。

验收标准：

- 图谱对象、所属关系与宿主列表一致，同名工作区能够区分。
- 点击操作打开正确对象，筛选正确且不改变底层记录。
- 拖动后刷新和重启仍保留位置，状态事件不会打乱布局。
- 切换工作区不串布局，多窗口冲突有明确处理。
- 对象消失、权限不足、存储失败均有可恢复的界面状态。
- 禁用/卸载后没有残留入口、重复订阅或定时器。
- 在记录的环境用约 200 个可见节点检查拖拽、缩放和筛选，大量会话按需加载。
- 图形操作不改变工作目录、会话所属、文件或历史。

注意稳定 ID、旧布局迁移、名称变更、卸载期间异步保存、未加载数据与已删除数据的区别。
