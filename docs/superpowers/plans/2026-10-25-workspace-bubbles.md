# 工作区气泡交互优化 Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans（如果执行环境提供）逐项实施并勾选清单；由电脑端 Sol 执行。本文件是功能交接清单，尚未读取项目源码，不代表已验证的代码级补丁计划。先完成任务 0，再落地到真实文件，禁止虚构路径、接口或插件能力。

**Goal:** 在现有工作区气泡界面中实现八项优化，兼顾层级清晰、操作稳定、轻量物理效果及对话可检索性。

**Architecture:** 沿用项目现有架构，将展示筛选、工作区展开、真实运行状态、物理布局和摘要展示分开管理。牵引和碰撞共享一个运动更新过程；摘要通过可替换的提供方接入并缓存，缺失时展示标题。

**Tech Stack:** 由 Sol 阅读现有仓库后确认，复用已有框架与依赖，不为这份清单重新搭建项目。

**Spec:** 本文“已确认需求”“建议默认规则”即随附设计依据。用户明确要求先生成执行清单，之后交给电脑端 Sol；本轮未实施代码、未发布。

## 已确认需求

1. 左下角状态栏支持同时选择多个状态。
2. 拖动气泡能牵引连接的整体，模拟绳子连接物体的效果。
3. 增加颜色选择器，允许自由设置主题颜色。
4. 工作状态醒目，能明显区分工作与非工作。
5. 气泡支持碰撞检测、自动避让和弹开，避免重叠。
6. 区分早期／近期对话，以及常用／不常用对话。
7. 工作区为深色气泡；点击后进一步变暗并展开浅色对话气泡。刚进入界面仅显示工作区和当前正在对话的小气泡。
8. 鼠标悬停对话气泡时显示对话概括，文字按顺时针顺序均匀分布于圆周，并缓慢旋转。自动概括优先考虑社区现有插件；用户没有指定具体插件。

## 建议默认规则（实施起点，不冒充用户逐项指定的参数）

- 环形文字顺时针绕气泡运动，单字保持屏幕正立；默认 45 秒一圈。悬停 200 毫秒后显示，移出气泡及文字环后延迟 150 毫秒隐藏。这些数值集中配置，可通过实际体验调整。
- 再次点击工作区收起其对话；当前对话始终保留。允许多个工作区同时展开。
- 当前对话指应用实际选中的会话；工作中指应用实际报告的任务运行状态，两者独立。
- 状态筛选同一维度取“或”，状态／时间／频率不同维度之间取“且”。无状态选中等同于“全部”。
- 工作区作为导航锚点始终可见；筛选主要作用于展开的对话。当前对话属于常驻例外，即使不符合筛选仍保留，并用“当前”标识说明。
- 首次进入／重新进入界面从折叠态开始；无当前对话时只显示工作区。设置可保存，但不恢复全部展开状态，避免违背初始显示要求。
- “近期”默认按最近一次有意义的会话活动计算：发送消息或收到新回复，距今不超过 7 天；“早期”为超过 7 天。只有可靠创建时间时可用创建时间回退，但需记录依据。
- “常用”默认按最近 30 天主动进入会话的次数计算，同一会话 30 分钟内重复进入只计一次，达到 5 次为常用。悬停、重绘、自动恢复不计使用。若历史数据缺失，标为“使用记录积累中”，不得当成真实零使用。
- 短概括默认目标为 12—24 个可见字符；实际环形容量由半径、字号与间距计算。太长时保留省略号，并提供完整摘要的静态阅读入口。默认字号不低于 12 CSS px，不以无限缩字解决拥挤。
- 提供减少动态效果选项：关闭旋转、回弹和呼吸动画，保留状态标识与避让结果；尊重系统减少动态效果偏好。
- 暂不增加按气泡逐个配色、批量改历史会话、后台批量调用模型等额外范围。

## Approaches / 方案选择记录

- 所有节点持续运行物理模拟：趣味明显，但阅读与点击容易受干扰，静止时仍有性能成本。
- 所有节点刚性同步移动：实现简单，但缺少绳子绷紧与逐步牵引感。
- 建议采用：交互期间轻量物理模拟，结束后阻尼收敛并休眠；悬停期间稳定目标节点。该方向在讨论中提出，用户未反对；具体算法和数值由 Sol 根据现有实现调整。

## Global Constraints

- 复用原项目、原数据与已有状态事件；不修改无关功能，不覆盖用户未提交的工作。
- 展开／收起、当前会话、任务运行、筛选命中分别存储，不用一个布尔值代表多个含义。
- 主题色、层级明暗、展开变暗、工作状态强调分别计算，工作状态不得只依赖颜色。
- 无实际运行事件就不能把“打开会话”猜成工作中；无真实摘要就显示标题，不伪称模型概括。
- 所有动画采用时间步进，避免刷新率影响速度；无活动时停止物理循环，离开界面释放监听和动画。
- 不因悬停自动向未知外部服务发送对话。插件接入必须先核实数据来源、接口、权限与成本。
- 本清单不授权发布包、部署生产、提交市场或升级付费服务。

## Review Focus

- 当前会话不存在、被删除或跨工作区切换：可见集合及时更新，不产生重复节点或幽灵连接。（任务 1）
- 靠近屏幕边缘、窗口缩小和节点过密：不把气泡推到不可访问的位置，不无限抖动。（任务 4）
- 深浅极端主题色：工作区与对话仍可区分，文字仍清晰，工作状态仍可辨。（任务 3）
- 快速切换悬停对象、异步摘要乱序返回：旧会话摘要不能覆盖新会话，移出后不突然重现。（任务 7）
- 运行中任务被取消、失败或结束：及时退出工作中；多个并行任务必须全部结束才清除聚合运行态。（任务 3）

## 任务 1：工作区层级与展开（需求 7）

- [x] 为工作区展开集合、当前会话和筛选状态分别建模，使用稳定 ID。
- [x] 实现初始可见集合：全部工作区 + 实际当前会话（存在时）；当前会话只出现一次。
- [x] 点击工作区使其进一步变暗，展开所属浅色对话；再次点击收起，保留当前会话。
- [x] 切换当前会话时重新计算可见集合：旧会话仅在所属工作区展开且筛选通过时保留。

- [x] 编写有意义的可见集合测试：无当前会话、已删除会话、跨工作区切换、重复展开、收起保留当前会话。

验收：进入界面没有全部对话同时铺开；展开与收起不丢数据、不重复节点。

## 任务 2：状态多选（需求 1）

- [x] 将单值筛选改为集合，点击一个状态只切换该项，不清除其他选项。
- [x] 增加“全部／重置”，清空选择按全部处理。
- [x] 明确筛选是“状态 A 或状态 B”，不是要求一个会话同时具备两种互斥运行状态。
- [x] 仅匹配现有真实状态，不臆造状态；当前会话保持可见并标记“当前”。
- [x] 筛选变化同步更新可见节点、连接线与碰撞对象；隐藏节点不参与碰撞。
- [x] 验证多选并集、全部取消、无匹配结果提示、当前会话不匹配但常驻。

验收：多选不退化为单选，隐藏项没有留下不可见碰撞体。

- [x] 增加主题色选择器、预设色、HEX 输入与恢复默认；无效色值显示提示且不破坏当前主题。
- [x] 从主题色派生工作区深色、展开更深色和对话浅色；避免简单透明叠加造成不可预测的层级。
- [x] 保证文字、描边和背景可辨；普通文字对比度目标至少 4.5:1。
- [x] 通过现有设置机制保存合法颜色，重启恢复；损坏或旧设置安全回退。
- [x] 以真实任务事件驱动“工作中”标识：文字／图标 + 明确轮廓，轻微呼吸动画为辅助。
- [x] 工作区存在任一运行中子任务时显示聚合运行标记；完成、失败、取消与断线未知状态分别处理，不让状态永久卡住。
- [x] “已展开变暗”“当前会话描边”和“工作中标识”可同时表达，互不覆盖。
- [ ] 验证极深、极浅、低饱和主题，以及任务并发、取消、失败和重新连接后的状态。 （主题、聚合和适配器回归已过；真实模型取消/失败/断线重连尚未实测。）

验收：改变主题后仍可一眼辨认工作区／对话、展开／收起、当前／运行中。

## 任务 4：统一牵引与碰撞（需求 2、5）

- [x] 优先扩展已有拖拽／布局实现；牵引、碰撞、边界约束共享一次更新过程，避免两个系统互相修正。
- [x] 拖动节点为鼠标约束点，准确跟手；相连节点按连接关系传递牵引，不把所有气泡当一张图片同步平移。
- [x] 默认允许连接线在一定长度内松弛，超过连接长度后才施加拉力，形成绳子绷紧感。
- [x] “整体”指被拖气泡所属的连接结构：会话牵动工作区及其他可见相连节点；独立工作区不隔空跟随，但可以受直接碰撞推动。若现有图有全局连接则按真实连接传播。
- [x] 隐藏会话不渲染、不碰撞；其布局可在父节点移动后更新局部坐标，避免展开时遗留在屏幕外。
- [x] 加入碰撞检测、轻微分离及有限回弹；按实际气泡半径和间距计算，不用一个固定半径覆盖所有节点。
- [x] 拖动节点位置优先，其他节点让路；不要用碰撞响应把鼠标抓住的节点弹离指针。
- [x] 松手后阻尼收敛，速度与位置修正量同时低于阈值时进入休眠，避免持续轻微抖动。
- [x] 加入边界约束；空间不足时优先扩展可平移画布并提供回到视野入口，若容器不支持则提供折叠分组／数量入口，不持续强行挤压。
- [x] 悬停目标节点保持稳定，其他节点围绕其约束位置避让；开始拖拽后撤销悬停约束。
- [x] 验证链式牵引、不同尺寸气泡、快速拖拽、角落拥挤、窗口缩小、收起后的碰撞清理。
- [x] 以 10、50、100 个可见节点进行实际性能测量，记录测试设备与结果；静止时物理计算应停止，不能仅凭观感声称性能达标。

验收：有绳子拉动的延迟感，有碰撞弹开感；松手后稳定、不重叠、不逃出可访问范围。

## 任务 5：时间与使用频率分类（需求 6）

- [x] 依据上述默认规则分别计算时间分类与频率分类，不把“旧”直接等同于“不常用”。
- [x] 为两个维度提供清楚的筛选入口，并与状态筛选组合。
- [x] 数据使用现有历史记录优先；缺失时从本次版本开始累计，显示记录不足状态，不伪造过去的使用量。
- [x] 增加手动置顶能力，置顶影响排列优先级，不自动覆盖用户明确的筛选，也不等同于“常用”。
- [x] 在可用位置显示最近活动时间和使用频率文字／标记；不再占用工作中提示的颜色含义。
- [x] 保存新增使用记录与置顶设置，确保老数据兼容；仅移动鼠标、旋转动画或重绘不写入使用计数。
- [x] 验证近期但不常用、早期但常用、7 天边界、30 天滚动窗口、去重计数、历史缺失及重启恢复。

验收：两个维度能独立组合，规则能解释，记录不会被悬停和自动刷新污染。

## 任务 6：旋转环形摘要展示（需求 8 的视觉部分）

- [x] 悬停对话气泡后显示摘要文字环；悬停工作区不误用某个会话摘要。
- [x] 文字按 Unicode 可见字符簇拆分，避免拆坏 emoji、组合字符；按实际字符数均匀分配圆周角度。
- [x] 初始阅读起点在顶部，字符顺序沿顺时针排布，整体默认 45 秒顺时针一圈。
- [x] 单字保持屏幕正立，仅位置绕圆运动，避免转到下半圈时倒着读。
- [x] 优先展示短摘要，容量不足时截断并标记省略；提供静态完整摘要阅读入口，不无限缩小字体。
- [x] 气泡与文字环共同构成悬停区域，允许指针从气泡进入文字而不中断显示。
- [x] 同时只显示一个活动文字环；摘要浮层置顶并预留外圈空间，靠近边缘时调整位置／视野以免裁切，不让文字环触发持续碰撞。
- [x] 拖动期间隐藏摘要环，松手后重新判断悬停；移动／缩放后文字位置和气泡保持一致。
- [x] 支持键盘焦点触发及静态可读文本；减少动态效果开启时保持文字环静止。
- [x] 验证中文、英文、混排、emoji、极短／极长标题、小气泡、屏幕边缘及快速进出悬停区域。

验收：文字均匀环绕、缓慢顺时针旋转且正立，能稳定阅读，没有闪烁或裁切。

## 任务 7：摘要来源与社区插件接入（需求 8 的内容部分）

- [x] 先检查现有项目是否已有标题、摘要字段或社区插件接口，再调查用户实际使用平台的兼容插件。
- [ ] 核实候选插件的真实接口、当前兼容性、数据权限、费用和可读取结果；没有证据时不得宣称“已接入”。 （待接入：目标版本读取接口、权限和费用尚未完整证实；已完成候选调查。）
- [x] 优先读取现有摘要，预留可替换的摘要提供方；无兼容插件时先完成标题回退和手动短概括，不阻塞其余功能。
- [x] 内容优先级：手动概括 > 有效的插件摘要 > 原会话标题 > “未命名对话”。保留来源标记，标题回退不标为自动摘要。
- [x] 按会话 ID 和内容版本／可靠更新时间缓存摘要；无内容版本时使用可靠内容指纹，不每次悬停请求模型。
- [x] 仅在确有内容变化时使缓存失效；同一会话请求去重，异步返回校验会话 ID 与内容版本。
- [x] 插件失败、未安装、超时、返回空值或超长内容时保留可用回退，不阻断交互。
- [x] 仅将摘要当文本显示，不当 HTML 或可执行指令；不自动安装不明插件、输入凭据或开启付费 API。
- [x] 真实调用需要既有授权；没有授权时只完成适配接口和模拟验证，报告阻塞条件。
- [x] 验证 A、B 会话交替悬停、A 请求晚于 B 返回、移出后返回、对话删除后返回、内容更新后旧摘要返回。

验收：没有插件也能正常显示标题环；真正接入时可证明来源、缓存、失败回退与乱序保护有效。
