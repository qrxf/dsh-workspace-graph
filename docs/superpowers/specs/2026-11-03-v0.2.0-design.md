# 工作区图谱 0.2.0

用户要求：工作状态非常明亮的发光；读取其他工作区记忆时显示特殊连线；Web、桌面与最新 DSH 适配；发布 0.2.0 并更新 README。用户已选择“读取关系线＋记忆详情”，原插件继续负责记忆管理。

## 方案与范围

采用现有图谱加只读记忆适配层。复用 dsh-continual-evolve 的中央 SQLite 数据结构，不修改其代码、记忆或统计。复制整套记忆管理会产生第二个写入方，不符合已选范围；仅复用 HTTP 卡片接口不能覆盖 Electron 的 file/IPC 模式，也缺少跨工作区读取明细，因此使用宿主 Remote 通道提供只读投影。

## 行为

- 运行中与等待回应使用高亮核心、饱和状态色和更宽外晕。工作状态的发光优先于“当前”冰蓝色；当前白圈保留。呼吸低谷仍非常明亮，减少动态效果时静态高亮，文字保持清晰。
- 紫色有向虚线从读取工作区指向记忆来源工作区，图例说明方向。双向读取显示两个方向；多个记忆合并为同一方向的关系。端点保持圆周连接，拖动时更新。
- 关系依据 memory_usage 中实际正文读取记录，并解析 memories 的 origin_workspace 或确切的 source_session 所属。尊重本地同 ID 记忆遮蔽全局记忆，排除自身、未知来源与仅存在/索引注入。旧版计数缺少逐次读取时的来源快照，详情必须说明按现有记录解析，不能承诺还原删除或变更前的完整历史。
- 工作区详情显示自身及可见全局记忆、类型、来源、读取次数、最近读取时间；正文点击后按需读取。查看图谱不会增加模型读取计数。提供刷新和未安装、空数据、读取失败状态。
- 记忆线是展示覆盖层，不加入树布局或拖动绳索约束，不改变工作区与会话归属，也不强行显示被过滤的端点。

## 宿主与兼容

只读宿主适配通过 DSH 原生 Remote 在 Web 与 Electron IPC 上调用，继承宿主访问控制，限制为当前获准工作区与其可见记忆。数据库路径来自 DSH_HOME 或用户目录，不接受客户端任意文件路径，使用 node:sqlite readOnly 打开既有文件，不创建数据库或迁移结构。缺文件、缺模块或不兼容 schema 应可降级，图谱基础功能继续可用。

检查 npm 当前发行标签；以最新可用常规版本为开发目标，并验证现有 rc.4 Web 与 rc.5 桌面运行契约。宿主实例和用户 profile 不擅自升级或重启。桌面入口及原生通道在隔离环境验证；无法完成的真实 Electron 验证明确记录。

## 验证与发布

补充合成数据库测试：读取证据、来源解析、遮蔽、同名路径、双向关系、空/损坏数据库、只读保证。浏览器检查高亮、记忆详情、连线与拖拽独立性。运行单元、类型、构建、相关交互和隔离宿主检查，检查发布包；更新 README、版本与发布说明后按仓库既有渠道发布 0.2.0。发布已获用户明确授权。

具体颜色强度、组件拆分、查询与刷新实现由实施者决定。数据库 schema 若缺少可靠读取证据，不推测关系，以可用性提示说明。
