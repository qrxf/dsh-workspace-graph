# 0.2.0 验证记录（2026-11-03）

环境：Windows、Node 24.21.0、系统 Edge、DSH 0.2.1-rc.4 / rc.5。所有开发、构建和测试位于 D:\Project\dsh-workspace-graph。

- 91 项单元测试通过，含新增记忆存储/权限测试；TypeScript 类型检查、客户端及宿主构建通过。
- 合成 SQLite 验证实际正文读取与来源归属、仅索引注入不连线、双向独立关系、本地 ID 遮蔽、归档的提升指针、POSIX 大小写、重复路径歧义、缺失/损坏/不兼容数据库。数据库打开只读，查看前后数据库字节不变，缺失文件不被创建。
- 1440/850/720/390px 操作栏与提示无重叠；运行/等待/新结果/当前光晕存在；当前等待节点保持金色状态光晕，运行/等待的外晕加亮、扩大至 64px 模糊层，最低呼吸亮度 0.94。
- 记忆浏览器流程验证双向虚线与箭头、按需正文、刷新、选择隔离和拖动端点更新。
- DSH rc.4 / rc.5：使用临时 DSH_HOME、独立端口、合成工作区与记忆数据库，验证真实动态客户端加载、快照、记忆箭头、按需正文、原生工作区重命名与新建会话、并行 mainView、Ctrl 拖动、刷新重置布局与导航。没有页面错误。
- 无 HTTP 服务的原生测试：真实 Cordis、Typert Gateway 和 Client Connection，以进程内载体调用同一 `/api` 接口，验证快照、正文、非 owner/未知工作区拒绝及插件卸载。
- 发布包在源码仓库之外的独立临时目录中，以 `--omit=dev --ignore-scripts` 安装并成功导入宿主入口，确保开发依赖不会掩盖发布包缺依赖。发布包明确包含官方协议运行依赖。
- 既有交互回归：首次居中、搜索/返回、备份导入导出、1,000/5,000 会话目录、密集环、圆周端点、Ctrl 拖动、柔性牵引、30/60/120Hz 松手恢复、运行布局、隐藏层级、嵌套工作区、稳定视角与生命周期清理通过。

## 调查与修正

- 基线为图谱 0.1.2、DSH rc.2 开发依赖；81 项单元测试通过。用户 Web profile 为图谱 0.1.1，桌面 profile 为 0.1.2，插件版本与宿主版本分别管理。
- npm 当前 latest/next 为 0.2.1-rc.5，alpha 为独立通道。rc.2 旧锁与 rc.5 peers 冲突，备份旧模块和锁后干净解析 rc.5，未使用强制忽略 peers。
- 原记忆插件 Web 卡片接口不适合直接用于 Electron；改用标准 Remote 服务，不注册独立 HTTP 记忆端口。
- 新记忆详情与工作区操作曾使用相同 React key，层级回归检测到警告；改为独立 memory 前缀后重跑层级、交互与生命周期通过。
- 原生测试曾假设所有边都是所属关系边；扩展为同时检查记忆圆周端点。
- 独立代码审查发现并复现三个发布问题，均增加回归后修复：生产包缺官方协议运行依赖；同目录不同原始分区字符串混淆同 ID 记忆；同名列中的异常 BLOB 值导致 React 无法渲染。分区现在优先精确原字符串，仅在唯一别名时回退；元数据及正文均在存储边界校验类型。POSIX 根目录与全局空分区也单独回归。
- 2026-11-04 云端 Chromium 检测到既有导航测试在 React/物理投影更新前立即计数的竞争。展开和恢复默认的断言改为等待真实 DOM 状态，随后再检查结果；没有增加固定延时或重复点击。

## 验证范围
