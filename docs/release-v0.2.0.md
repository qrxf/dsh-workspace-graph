# v0.2.0

- 工作状态改为非常明亮的状态色多层光晕：运行中蓝色、等待回应金色，新结果绿色；当前会话不覆盖工作状态颜色，减少动态效果时保持静态高亮。
- 对接 dsh-continual-evolve 0.19.3 的只读记忆元数据。以紫色有向虚线连接“读取方 → 记忆来源方”，双向读取分别显示，多个记忆按方向合并。
- 工作区详情可查看项目/全局记忆、来源、正文读取次数、最近读取时间及按需加载的正文。手动刷新及 15 秒元数据刷新不修改原记忆或计数。
- 记忆读取使用原生 `/api` Remote 与 Connection，适配 Web 与桌面 IPC；拒绝非 owner、已销毁或取消的调用。缺数据库、SQLite 或兼容结构时基础图谱继续可用。
- 开发依赖升级并固定到 DSH 0.2.1-rc.5；rc.4 / rc.5 隔离真实宿主均已验证，无 HTTP 服务的进程内原生通道测试通过。CI 原生验证增加两版本矩阵。
- README 更新安装 profile、发光规则、记忆读取证据、只读边界及兼容验证范围。

记忆线只依据原插件按 ID 读取正文的累计记录及现有来源信息；索引注入、搜索命中不连线，无法还原已删除或来源变更前的完整历史。仅连接当前可见的两个工作区。线条不进入布局或物理约束，拖动仍只改变展示位置。

验证与限制见 [验证记录](verification-2026-11-03.md)。真实 Electron 窗口未实测；已验证其使用的原生进程内通信契约。无需额外模型调用或 API 密钥。
